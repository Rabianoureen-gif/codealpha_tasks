# CodeAlpha Frontend Development Internship Tasks

This repository contains the projects completed during my Frontend Development Internship at **CodeAlpha**.

## Completed Tasks

### Task 1: Personal Portfolio Website
A clean, pastel-themed, responsive personal portfolio website built with pure **HTML5** and **CSS3**.

- **Features:**
  - Smooth single-page navigation (`About`, `Skills`, `Projects`, `Contact`)
  - Responsive layout for desktop, tablet, and mobile screens using Flexbox, CSS Grid, and `clamp()` typography
  - Interactive skill pills, project showcase cards, and direct contact links
- **Tech Stack:** HTML5, CSS3
